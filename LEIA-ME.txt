CLÓVIS X LOTUS - VERSÃO OFFLINE CORRIGIDA

Extraia todo o ZIP e abra index.html no navegador.
O PDF e a fonte Arial estão incorporados em assets/embedded.js.
Não precisa de servidor local nem conexão com a internet para gerar o PDF.
Mantenha a pasta assets junto dos arquivos HTML, CSS e JavaScript.

Para publicar, envie todo o conteúdo extraído para a pasta pública da hospedagem.
O formulário funciona como site estático, sem banco de dados e sem instalação de pacotes.
O endereço externo das regras precisa de internet para ser aberto.
